# Student banners (v13)

Right-side hero artwork for the Student module. Heading, description and
feature chips are rendered in HTML by `StudentPageBanner.jsx`.

| Page             | File                         |
|------------------|------------------------------|
| My Courses       | `myCoursesBanner.webp`       |
| My Batch         | `myBatchBanner.webp`         |
| Class Schedule   | `classScheduleBanner.webp`   |
| Recordings       | `recordingsBanner.webp` (+ `recordingsEmpty.webp` empty-state art) |
| Attendance       | `attendanceBanner.webp`      |
| Course Materials | `courseMaterialsBanner.webp` |
| Assessments      | `assessmentsBanner.webp`     |
| Progress         | `progressBanner.webp`        |
| Profile          | `profileBanner.webp`         |
| Certificates     | `certificatesBanner.webp`    |
| Settings         | `settingsBanner.webp`        |

To swap art, replace the file (keep the name) or edit
`src/features/student/constants/studentBanners.js`.
